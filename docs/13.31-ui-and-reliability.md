# Samba 13.31: graphics and acquisition reliability

This release keeps the existing PyQt6/Matplotlib applications and data formats.

## Graphics and layout

- Presets, Channels and Storage can be shown independently; panel visibility and splitter positions are saved separately for Green/IR and Cryo.
- Settings and calibration forms scroll. Wide trajectory rows stack when the viewport is narrow. Shared point-based type and higher-contrast secondary text improve readability.
- The acquisition header distinguishes Ready, Preparing, Running, Paused, Stopping and Error. Simulation/hardware mode and lock protection are visible. Progress details remain accessible from the compact status bar.
- Live 1D plots have Follow live and Fit. Manual pan or zoom holds the selected limits as new data arrives. Channel colors and line styles stay tied to channel identity.
- Live and browser maps use explicit sample-cell boundaries, including descending and nonuniform axes. Missing cells are gray. Map options provide physical aspect, fixed color limits, cursor values and horizontal/vertical profile snapshots. Switching map sensors restores automatic color scaling; display-unit changes rescale held color limits.
- Export supports PNG, PDF and SVG, physical width/height, text size, resolution, legend visibility and an editable provenance caption. Exports use a light copy and do not restyle the live view.
- The existing redraw throttle is retained. No speculative acquisition or rendering optimization was introduced.

## Data and lifecycle fixes

- Setup and device-registry JSON saves use a flushed temporary sibling and atomic replacement. Failed saves preserve the old file and report an error. Cryo now correctly backs up unreadable JSON.
- NAS sync defers running HDF5 files, detects changed same-size files, verifies copied contents and publishes atomically. A small destination index avoids repeatedly hashing unchanged files. Sync errors now reach the caller, and Qt signals deliver completion on the GUI thread.
- Legacy `/measurement` files can be discovered again. Failed file inspection records a diagnostic. Analysis CSV and comparison-image exports no longer reference undefined variables.
- Acquisition workers own copied configuration snapshots. Settling waits respond to cancellation. Closing waits asynchronously for scan, autofocus, readback and other tracked QThreads to finish before releasing ownership; data writers are never forcibly terminated.
- Aborted runs do not show 100% completion or start the automatic post-scan demagnetization path. Existing click-only Pause/Abort behavior is preserved.

## SetupLock rollout

The companion `jakusbs/TANGO_Devices` change introduces atomic owner-checked leases in `tango_servers_new/SetupLock` version 2.0.0. Install/restart it while all rigs are idle, then upgrade every Samba workstation. The device name remains `hpp-N42/samba/lock`.

New clients renew 180-second leases every 30 seconds. Failed renewal pauses acquisition; it must be renewed successfully before Resume. Release requires the same owner token. A busy legacy server is never taken over merely because its timestamp is old.

Old servers remain supported in explicitly labelled **Advisory lock** mode. If the optional service cannot be reached at acquisition start, the historical fail-open policy remains and the header says **Unprotected**. Mixed old/new clients cannot provide an atomic ownership guarantee. Leases control admission and cooperative software behavior; they do not stop an autonomous instrument or replace its interlocks.

No laboratory device server is deployed by this change. Verify a short simulated run first, then a supervised short run on each rig, including two-workstation contention, renewal interruption and normal release, before routine acquisition.

## Packaging and maintenance

```sh
python -m pip install '.[gui]'
samba
samba-cryo
```

Add `hardware` for PyTango and `analysis` for SciPy/pandas. Existing script launchers remain supported. Shared core modules use qualified imports; application-specific compatibility shims are retained for existing lab launchers. The pure scan runner no longer imports Qt. Typed request/channel boundaries preserve existing config and HDF5 representations.

Shared widgets, channel pickers, status calculation and window lifecycle now live under `core/`, reducing duplicated Green/IR and Cryo logic. CI runs Python 3.10 and 3.13, undefined-name checks, the existing engine tests, real offscreen Qt/Matplotlib tests and both application smoke tests.

Local validation: 251 existing engine tests, 20 added regressions, both real application smoke tests at 1280×800, and the lock store's four tests (including 16 simultaneous contenders). Live instrument behavior requires lab validation. The local sandbox cannot enumerate network interfaces for TANGO's native test server; its real command test is included in the companion CI workflow.
